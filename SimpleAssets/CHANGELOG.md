# Changelog

## 2.0.1

- Fixed resource loading initialization failures when no nearby address space is available for hook trampolines

## 2.0.0

- [For Modders] Custom compiled textures, materials, particles, units and animations (very unstable)
- [For Modders] Replace builtin assets (unstable)
- [For Modders] Breaking change: APIs for fonts, mouse cursors, videos and slug albums are changed (see Document), APIs for textures are not affected

## 1.2.0

- [For Modders] Supported custom fonts, mouse cursors, videos and slug albums

## 1.1.0

- Fixed a compatibility issue with Simple Audio mod
- [For Modders] Directory texture loading now accepts an empty path to load directly from the calling mod's `assets` directory

## 1.0.0

- Initial release
